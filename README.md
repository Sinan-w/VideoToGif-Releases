# VideoToGif

一款将本地视频片段转换为 GIF 动图的轻量级 Android 工具。

## 功能

- 本地视频导入
- 视频片段截取
- 画面裁剪
- 帧率和播放速度调整
- 正放与倒放
- GIF 生成与保存

## 支持平台

Android 8.0 及以上。

## 安装说明

下载 APK，在 Android 手机上打开安装。如系统提示，需要允许对应来源安装应用。

## 使用说明

视频在本地处理，无需上传到服务器。
